- Asset: Map Sprites
- Source: https://www.spriters-resource.com/game_boy_advance/fireemblemthesacredstones/asset/53755/

- SHA-256: `73E559C8072EF954CFBAD858227EBF1AD0518609C206F47B4BB99BB968B7D9B2`

These game assets are copyrighted by their respective owners (Nintendo / Intelligent Systems). They were downloaded for local prototype and reference use. Do not redistribute or use commercially without the necessary permission.

The project reads this sheet locally through `FE8MapSpriteImporter`. The
importer currently recognizes the labelled Recruit and Brigand blocks, removes
the sheet backgrounds, applies the original FE8 faction palettes, and builds
`FE8MapSpriteAnimation` resources in memory. The PNG is intentionally ignored
by Git so public clones use the project's fallback unit visuals.
